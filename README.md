## 🚀 Featured Projects

### 🗑️ 1. Garbage Detection Using CCTV

An object detection system built using YOLOv8n to identify 8 waste-related object classes from CCTV footage.

- Trained using a Roboflow dataset.
- Achieved 85.14% precision.
- Achieved 93.33% recall.
- Achieved 97.00% mAP@0.5.

**Technologies:** `Python` `YOLOv8n` `Computer Vision` `Roboflow`

🔗 [View Repository](https://github.com/ThanushaPrakash/Garbage-Detection-Using-CCTV)

---

### 🧑‍💻 2. Face Recognition and Verification

An end-to-end face recognition pipeline combining MTCNN for face detection, FaceNet for deep feature extraction, and KNN for identity classification.

- Detects and crops faces using MTCNN.
- Generates 128-dimensional facial embeddings using FaceNet.
- Performs identity recognition using KNN.
- Uses cosine similarity for identity verification.

**Technologies:** `Python` `MTCNN` `FaceNet` `KNN` `OpenCV` `Scikit-learn`

🔗 [View Repository](https://github.com/ThanushaPrakash/Face-Recognition-and-Verification-using-MTCNN-FaceNet-and-KNN)
